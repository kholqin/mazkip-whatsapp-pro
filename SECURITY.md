# Security Policy — MAZKIP WHATSAPP PRO

## 🔒 Data Security

- All target lists are encrypted using AES-256 (Fernet)
- Session data is stored locally only
- Configuration files use encrypted storage
- Logs do not contain plaintext credentials

## 📋 Reporting a Vulnerability

If you discover a security vulnerability in MWP, please:

1. **DO NOT** create a public GitHub issue
2. Contact the author privately
3. Include detailed steps to reproduce

## ⚠️ Responsible Usage

This tool is designed for:
- Authorized penetration testing
- Security research
- Educational purposes only

**Illegal use is strictly prohibited.**
