# Code of Conduct — MAZKIP WHATSAPP PRO

## Our Pledge

We are committed to providing a safe environment for security researchers and ethical hackers.

## Standards

**Expected:**
- Use this tool only on systems you own or have explicit permission to test
- Follow responsible disclosure practices
- Respect others' privacy

**Unacceptable:**
- Using this tool for harassment or illegal activities
- Distributing modified versions for malicious purposes
- Removing author credits

## Enforcement

Violations will result in permanent ban from the project.
